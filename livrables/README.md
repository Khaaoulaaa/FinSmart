## Etat actuel

Le Sprint 2 est considere comme cloture pour le prototype. Le projet dispose maintenant d'une gestion des depenses complete pour le perimetre actuel, d'une authentification demo, de roles utilisateurs, de protections de routes, d'une facturation de base et de tests associes.

Les elements principaux realises sont :

- backend FastAPI ;
- base PostgreSQL ;
- fonctionnalite depenses ;
- tests backend associes ;
- frontend React ;
- authentification demo ;
- roles utilisateurs ;
- categories de depenses ;
- facturation de base ;
- pipeline CI ;
- configuration de staging ;
- documentation de conception.
